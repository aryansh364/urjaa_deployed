# Urjaa Solutions Website

Frontend development for the Urjaa Solutions website built using React and Vite.

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- React Router DOM

## Project Structure

```
src/
├── assets/
├── components/
│   ├── layout/
│   ├── sections/
│   └── ui/
├── constants/
├── data/
├── hooks/
├── layouts/
├── pages/
├── routes/
├── styles/
└── utils/
```

## Getting Started

Clone the repository and install the dependencies.

```bash
npm install
```

Start the development server.

```bash
npm run dev
```

The application will be available at:

```
http://localhost:5173
```
